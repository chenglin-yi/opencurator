## 🚀 Features / 功能特点

- 🤖 **AI Optimization** / **AI优化** - One-click resume optimization with multiple AI providers
- 📊 **Resume Scoring** / **简历评分** - AI-powered scoring with detailed feedback
- 📋 **JD Analysis** / **JD分析** - Match job descriptions automatically
- 📝 **Multi-Template** / **多模板** - 3 professional templates for different industries
- 📥 **Import** / **导入** - Import from Word and PDF files
- 📤 **Export** / **导出** - Export to Word and PDF with styling
- 🌙 **Dark Mode** / **暗色模式** - Light and dark theme support

## ⚡ Quick Start / 快速开始

```bash
# Clone / 克隆
git clone https://github.com/yourusername/opencurator.git

# Install / 安装依赖
cd opencurator
npm install

# Run / 启动
npm run dev
```

Open http://localhost:3001

## 📦 Build / 构建

```bash
npm run build
```

Upload the `out` directory to Edgeone or any static hosting.

上传 `out` 目录到Edgeone或任何静态托管服务。
